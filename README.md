# Vagus Records

Official website concept for Vagus Records, an independent melodic house and
techno label. The visual language draws from the vagus nerve, brainwave activity,
and the idea of music as an inner current.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Deploying to Vercel

Import the `vagus-records` GitHub repository into Vercel. Vercel will detect
Next.js automatically and use the standard `npm run build` command.
